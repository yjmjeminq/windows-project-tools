Link Evolution card pool through 2021

Scope: first OCG or TCG printing through 2021-12-31. The mod adds 1,424 cards absent from the base archive, including 126 cards first printed before 2020. Red Supernova Dragon is included. Each added card and all 10,027 non-token base cards have a three-copy grant. The BritishPiper catalog and saves are separate. The import skips tokens, skills, Rush Duel cards and records without a matching Konami database ID or available art.

Install on a separate game copy using Yu-Gi-Oh-Ex v1.6.1 and Mod Manager. Also install and enable the official Master Duel Engine mod from Mods.zip. Use the Yu-Gi-Oh-Ex loader and an offline duel. Three copies per card are granted for testing. Keep the original Yu-Gi-Oh! install and BritishPiper launcher separate.

Konami IDs connect the added cards to effects implemented by the Master Duel engine. The source Cards mod's experimental effect overrides are omitted. In-game rendering, game build compatibility, and the behavior of individual effects still need live tests. Card text and rules can differ between a 2021 printing and the version implemented in this engine.

Data and art: Yu-Gi-Oh-Ex v1.6.1, https://github.com/Arefu/Yu-Gi-Oh-Ex/releases/tag/v1.6.1
Release dates and Konami ID mapping: YGOPRODeck, https://ygoprodeck.com/api-guide/
